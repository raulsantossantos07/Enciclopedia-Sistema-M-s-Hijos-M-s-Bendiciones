# Enciclopedia y Compendio: Sistema de Más Hijos, Más Bendiciones

Compendio maestro interactivo, análisis completo de trama, personajes, sistema, poderes y guía corregida de *'De día salvo humanos, de noche lidero zombies'* (多子多福系统：白天救人类，晚上带领丧尸).

Abarca los 528 capítulos de la novela completa, los 10 arcos argumentales, los 1.032 hijos, las 500+ esposas y el epílogo de 16 años.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
